# RFC-0004: Marketplace

**Status:** Draft  
**Layer:** L6 Creator  
**Depends on:** RFC-0002 Plugins, RFC-0003 Creator

## Summary

Marketplace sells Platform Assets: Games, Templates, Assets, Logic modules — not isolated shop pages.

## Categories

Game · Template · Asset · Logic · NPC · Boss · Quest · Skin · Map · Stage · Shader

## Integration

All listings must use Replay Engine plugins. Logic Marketplace items map to `Replay.logic.*`.

## Non-Goals

- Payment processing (L7 Business)
- User-generated store without AI QA
