# RFC-0005: Replay Passport

**Status:** Accepted  
**Layer:** L4 Identity  
**Depends on:** L3 Gameplay

## Summary

Passport is the player's persistent identity layer — Level, Collection, Journey links, Creator dual identity.

## Scope

- `/passport` panel
- Living Identity, Collection %, Achievements
- Link to Journey, Community, Creator

## Data

localStorage + Supabase scores (device-based MVP)

## Non-Goals

- Public social profiles (L5 Community)
- Creator revenue (L7)
