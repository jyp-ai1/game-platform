# Tetris — Game Rules

## 원작 (Guideline Tetris)

10×20 · 7 pieces · line clear · level speed · spawn block = loss.

## Replay 적용

Standard engine · level = lines/10 · survival only.

## Rule Taxonomy

| | |
|---|---|
| **Difficulty** | Drop speed increases with level |
| **Stage** | Score ladder 500 → 10000 |
| **GameOver** | Spawn overlap |
| **Clear** | Line clears (score) |
| **Victory** | N/A (endless) |
| **Failure** | Stack blocks spawn |

## 차이점

- No hold / ghost / T-spin
