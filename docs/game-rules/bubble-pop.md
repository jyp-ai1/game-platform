# Bubble Pop — Game Rules

## 원작 (Puzzle Bobble / Bubble Shooter)

Hex grid · 3+ match · float bonus · bottom line loss · clear board win · ceiling pressure.

## Replay 적용

8×12 grid · 5 colors · ceiling every 8 shots (after snap) · +10 pop / +20 float.

## Rule Taxonomy

| | |
|---|---|
| **Difficulty** | 5 colors; ceiling drop every 8 shots |
| **Stage** | Score ladder 300→6000 (journey; engine TBD Epic 2) |
| **GameOver** | Bottom row occupied after snap; ceiling overflow |
| **Clear** | N/A (single-board) |
| **Victory** | Empty grid |
| **Failure** | Bubble crosses bottom line |

## 차이점

- 2D hex approximation vs arcade physics
- Stage engine scaling not wired yet
