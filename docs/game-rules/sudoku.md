# Sudoku — Game Rules

## 원작 (Nikoli Sudoku)

9×9 · givens · fill valid · 3 mistakes = out.

## Replay 적용

Easy/Normal/Hard · 3 mistakes · win on complete board.

## Rule Taxonomy

| | |
|---|---|
| **Difficulty** | Easy 40 / Normal 32 / Hard 30 givens |
| **Stage** | Easy→Master ladder (Expert/Master TBD) |
| **GameOver** | 3 mistakes |
| **Clear** | Valid complete board |
| **Victory** | Puzzle solved |
| **Failure** | Third mistake |

## 차이점

- 5-stage ladder vs 3 engine difficulties
