# Air Hockey — Game Rules

## 원작 (Arcade Air Hockey)

Puck · paddles · first to N goals · timed match.

## Replay 적용

5 goals · 180s timeout · tie → player win.

## Rule Taxonomy

| | |
|---|---|
| **Difficulty** | AI paddle speed |
| **Stage** | Score ladder (journey) |
| **GameOver** | 5 goals or time limit |
| **Clear** | N/A |
| **Victory** | 5 goals before AI |
| **Failure** | AI 5 goals |

## 차이점

- 0-score timeout win possible (Batch 2)
