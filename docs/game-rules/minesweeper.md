# Minesweeper — Game Rules

## 원작 (Windows Minesweeper)

Grid · mines · numbers · flag · reveal all safe = win · mine = loss.

## Replay 적용

9×9 · 10 mines fixed · first click safe.

## Rule Taxonomy

| | |
|---|---|
| **Difficulty** | Grid + mine count (planned stages) |
| **Stage** | Round 1–5 ladder |
| **GameOver** | Mine clicked |
| **Clear** | All safe cells revealed |
| **Victory** | Board cleared |
| **Failure** | Mine detonation |

## 차이점

- Stage sizes not wired to engine
