# Epic 종료 보고 템플릿

> PM 승인·추천 작업 없음. Epic 종료 시에만 작성. 작성 후 다음 Epic 자동 시작.

```
==============================

Sprint{N}

{overall}%

{progress_bar}

Epic1 {status}
Epic2 {status}
...

------------------

오늘 완료

- ...

------------------

자동 수행

QA {PASS|FAIL}
Commit {hash}
Push {yes|no}
Preview {url}

------------------

Blocker

{없음 | 설명}

------------------

현재 작업

Epic{N} {name}

(계속 진행중...)

==============================
```

## Epic 상태 표기

- `완료`
- `진행중 NN%`
- `대기`

## 금지 섹션

- 내일 추천 작업
- "다음에 무엇을 할까요?"
- PM에게 방향 확인 요청
